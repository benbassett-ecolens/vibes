# Brand images

Replace these two files to change the app's look (keep the file names):

- `logo.png`   — the mark shown next to "Ecolens CRM" in the sidebar and on the login page. Square, 512×512 recommended, PNG with transparency.
- `favicon.png` — the browser tab icon. Square, 64×64 or larger.

Then deploy (`deploy/prod.sh`). Browsers cache favicons aggressively; a hard refresh or a new tab shows the new one.
